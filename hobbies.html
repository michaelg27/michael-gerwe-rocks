Duck, Penguin, Hummingbird Game · 2025

For my Software Engineering 101 class, I made my first proper Godot game. My client wanted a 3D platformer with birds, and that's exactly what I delivered. I used absolutely no AI because I really wanted to learn how to make a full game myself with only YouTube tutorials (thank you Brackeys) to learn from. I did not make the models myself, as there was no world I would have the time to do so. It's really rudimentary, and was just meant to be a fun little project. Only the code is on my GitHub page because the 3D models I used were too big.
